# Ionic Liquids Imputation Pipeline

## Description
This repository contains the code and data for the article:
*Missing Data Imputation and Exploratory Data Analysis of Ionic Liquid Databases.*

## Structure

- `data/` : raw and imputed data
- `results/` : figures and tables

## How to use
1. Run `code/01_imputation.R`
2. Run `code/02_pca.R`
3. Run `code/03_clustering.R`
